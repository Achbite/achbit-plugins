# Achbit Plugin Directory

English · [简体中文](./README.zh-CN.md)

Choose a category below to browse plugins. Categories with more than 25 listings continue on the next page. Each plugin page explains its purpose and links to the author’s source, license and versioned download.

| Browse by category | What you can add |
| --- | --- |
| [Skills](./categories/guidance.md) | Instructions that a model can follow in a conversation. |
| [CLI tools](./categories/cli.md) | Commands that Achbit can make available as tools. |
| [Services](./categories/service.md) | Services that run alongside a session. |
| [UI extensions](./categories/ui.md) | Themes and other extensions for the graphical interface. |

Open **Settings → Plugins → Marketplace** in Achbit. When a listing shows **Install & enable**, select it to install the author’s package on the connected Host. To import a ZIP from the **Version** link, open **Settings → Plugins** and choose **All → Add…** in the development version or **Installed → Add…** in the 0.7.85 release. A verification record identifies the publisher check or the version and platform that were tested.

To contribute, add or update `plugins/<kind>/<id>.md` and open a pull request. A maintainer reviews the source and package, then merges approved listings into the [directory](./plugins.json). [Submission guide](./CONTRIBUTING.md) · [Plugin template](./templates/plugin.md)
