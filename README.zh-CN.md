# Achbit 插件目录

[English](./README.md) · 简体中文

从下表选择分类浏览插件。每类超过 25 个条目时自动续页。打开插件说明页即可查看用途、作者源码和许可证，并下载指定版本。

| 浏览分类 | 可以添加的功能 |
| --- | --- |
| [技能](./categories/guidance.zh-CN.md) | 供模型在对话中执行的文字指引。 |
| [命令行工具](./categories/cli.zh-CN.md) | 可供 Achbit 调用的命令行工具。 |
| [服务](./categories/service.zh-CN.md) | 随会话运行的服务。 |
| [界面扩展](./categories/ui.zh-CN.md) | 主题和其他图形界面扩展。 |

在 Achbit 中打开 **设置 → 插件 → 插件市场**。条目显示 **安装并启用** 时，点击即可将作者的插件包安装到当前连接的 Host。要手动导入，可从插件页的 **Version** 链接下载 ZIP，再打开 **设置 → 插件**。开发版使用 **全部 → 添加…**，0.7.85 正式版使用 **已安装 → 添加…**。核验记录说明核实了哪位发布者，或在哪个平台安装过哪个版本。

投稿时，新增或更新 `plugins/<kind>/<id>.md` 并发起 PR。维护者审核源码和安装包，通过后合并收录到[目录](./plugins.json)。[投稿指南](./CONTRIBUTING.zh-CN.md) · [插件模板](./templates/plugin.md)

## 许可

本目录的原创代码、文档及条目介绍等目录材料，在贡献者拥有或获授权许可的权利范围内采用 MIT 许可证。再分发副本或其中的实质性部分时，请保留版权声明和许可声明。[MIT 许可证原文](./LICENSE)

插件页的 **License** 链接指向该版本适用的条款。外链源码、ZIP、截图和演示按各自权利人的条款使用。条目中的插件名与发布者名称用于识别项目，其徽标和商标的使用另受相应规则约束。

发现许可标注有误、安装包链接失效或某个条目需要下架时，请在[目录 Issue](https://github.com/Achbite/achbit-plugins/issues) 中附上插件 ID、版本和相关链接。
