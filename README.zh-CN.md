# Achbit 插件目录

[English](./README.md) · 简体中文

从下表选择分类浏览插件。每类超过 25 个条目时自动续页。打开插件说明页即可查看用途、作者源码和许可证，并下载指定版本。

| 浏览分类 | 可以添加的功能 |
| --- | --- |
| [技能](./categories/guidance.zh-CN.md) | 供模型在对话中执行的文字指引。 |
| [命令行工具](./categories/cli.zh-CN.md) | 可供 Achbit 调用的命令行工具。 |
| [服务](./categories/service.zh-CN.md) | 随会话运行的服务。 |
| [界面扩展](./categories/ui.zh-CN.md) | 主题和其他图形界面扩展。 |

在 Achbit 中打开 **设置 → 插件 → 插件市场**。条目显示 **安装并启用** 时，点击即可将作者的插件包安装到当前连接的 Host。也可以从插件页面的 **Version** 链接下载 ZIP，在插件设置中选择 **已安装 → 添加…** 手动导入；Achbit 0.7.85 使用这个入口。核验记录说明核实了哪位发布者，或在哪个平台安装过哪个版本。

投稿时，新增或更新 `plugins/<kind>/<id>.md` 并发起 PR。维护者审核源码和安装包，通过后合并收录到[目录](./plugins.json)。[投稿指南](./CONTRIBUTING.zh-CN.md) · [插件模板](./templates/plugin.md)
