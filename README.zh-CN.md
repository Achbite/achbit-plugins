# Achbit 插件目录

[English](./README.md) · 简体中文

Achbit 设置中的「插件市场」读取本仓库的 [plugins.json](./plugins.json)。每个条目都指向作者公开的源码、许可证和指定版本的下载包。已提供核验记录的条目还可链接到相应证据。

## 下载与安装

在市场中选择插件，查看作者、版本和许可证。点击「下载」会在浏览器中打开作者提供的下载地址。如果作者发布的是 ZIP，请保留压缩包，在 Achbit 的插件设置里选取本地 ZIP，预览后确认安装。安装和启用由本地 Achbit 实例管理。

## 投稿或更新条目

1. 在公开仓库发布插件源码并标明许可证，记录投稿版本所用的完整 Git 提交 ID。
2. 通过作者的发布页或公开下载服务提供该版本的独立安装包。ZIP 根目录必须包含受支持的清单文件或 `SKILL.md`，并随包提供插件所需的入口、资源和许可证文件。
3. 从本目录仓库的 `main` 分支创建开发分支，编辑 `plugins.json` 后提交 Pull Request。更新已有条目时沿用原目录 ID，更新版本、固定源码、适用的许可证链接和下载地址。
4. 在 PR 说明中附上源码、下载地址和可复现的核验步骤。维护者会检查能否公开访问、安装包与源码的对应关系、许可证类别和插件入口。作者也可附上说明核验范围的记录。

### 目录格式

顶层格式为 `{ "schemaVersion": 1, "plugins": [...] }`。下表最后两个字段选填。

| 字段 | 填写内容 |
| --- | --- |
| `id`、`name`、`description` | 唯一且稳定的目录 ID、显示名称和简明用途。 |
| `kind` | 取值为 `guidance`（Skill）、`cli`、`service` 或 `ui`。 |
| `author`、`version` | 发布者署名和本条目对应的插件版本。 |
| `sourceCommit`、`sourceUrl` | 完整的 Git 提交 ID，以及包含该 ID、指向源码目录、文件或提交的链接。 |
| `licenseKind`、`licenseName`、`licenseUrl` | 许可证类别、名称和适用于该版本的许可证原文链接。使用开源许可证时选择 `open-source`。源码公开、但条款对使用或分发另有限制且不符合开源许可条件时，选择 `source-available`。 |
| `downloadUrl` | 公开的 HTTPS 链接，指向作者为该版本发布的安装包。可使用带版本标签的发布附件，或固定 Git 提交中的文件。 |
| `repositoryUrl` | 选填，作者的项目主页。 |
| `verification` | 选填。有发布者身份核验依据时可填 `{"kind":"publisher"}`。有安装核验记录时可填 `{"kind":"installation","platform":"macos-arm64","version":"1.2.3"}`，其中平台和插件版本替换为实际值，版本须与条目一致。两者均可在 `evidenceUrl` 中附上公开记录。 |

外部链接使用 HTTPS。下载地址应支持匿名访问，并始终指向所填版本。浮动分支和 `latest` 链接可能在审核后改变。仅在有相应证据时填写核验信息。安装记录的结论只覆盖记录列明的平台、版本和操作。
