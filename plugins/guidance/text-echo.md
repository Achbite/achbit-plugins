# Text Echo

[English](#english) · [简体中文](#简体中文) · [Release / 版本](#release--版本)

## English

Returns the text you provide unchanged. Use it to try a declarative Skill in a conversation.

Enable the Skill and ask it to echo a short line of text. The package contains a plain-language procedure for the model.

## 简体中文

按原样返回用户提供的文本，可用来体验声明式 Skill。

启用技能后，在对话中请它原样返回一小段文字。包内的文字步骤供模型读取。
