# Example Theme

[English](#english) · [简体中文](#简体中文) · [Release / 版本](#release--版本)

## English

Changes the GUI accent color through the theme extension slot.

Enable the extension and open Achbit’s GUI to load the blue accent. The package contains a UI manifest and a JavaScript entry point.

## 简体中文

使用主题扩展槽位更换界面强调色。

启用扩展并打开 Achbit 图形界面，即可加载蓝色强调色。包内包含界面扩展清单和 JavaScript 入口。
